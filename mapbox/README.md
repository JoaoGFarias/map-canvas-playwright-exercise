# Mapbox / MapLibre canvas exercise

A single static page rendering a MapLibre GL JS map (Mapbox GL JS's
open-source, token-free fork — identical API, no account needed). Fixed
center/zoom on San Francisco, with a marker and a translucent "fire risk
zone" polygon so there's something visible on load.

## Install

```bash
npm install
```

## Run

```bash
npm start
```

Then open **http://localhost:8080** in a browser.
